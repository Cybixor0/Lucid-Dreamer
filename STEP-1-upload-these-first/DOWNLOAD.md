# Downloading and installing Lucid Dreamer

This app is not on Google Play. You download the APK from GitHub and install it
yourself. It takes about two minutes.

**Requirements:** Android 8.0 or newer. No Google Play Services, no account, no root.

---

## 1. Download the APK

Go to the **[Releases page](../../releases)** and open the newest release.

Under **Assets**, download the `.apk` file:

| File | What it is |
|---|---|
| `lucid-dreamer-vX.Y.Z.apk` | The signed release build. **Download this one** if it is there. |
| `lucid-dreamer-vX.Y.Z-debug.apk` | Fully functional, but signed with the standard Android debug key. Use this if there is no signed build. |
| `SHA256SUMS.txt` | Checksums, so you can verify the download (optional, see below). |

You can download it straight to your phone from its browser, or to a computer
and transfer it across.

> **Why two builds?** There is no shared signing key for a project like this.
> Whoever builds it signs it. A debug-signed APK installs and behaves
> identically; Android will just warn that the developer is unknown.

## 2. Allow the install

Android blocks apps from outside the Play Store by default, so you have to allow
it once, for whichever app you open the APK with.

**Stock Android:** tap the downloaded file. When you are told installs from this
source are blocked, tap **Settings**, turn on **Allow from this source**, then go
back and install.

**Samsung (One UI):** the same flow. If you want to find it manually:
`Settings → Apps → [your browser or file manager] → Install unknown apps → Allow from this source`

You can turn that permission back off afterwards. It only controls installing.

## 3. Install

Tap **Install**. Android may say the app was not scanned by Play Protect, or
offer to send it to Google for scanning — that warning appears for every
sideloaded app. You can decline and install anyway.

## 4. Set it up

Open the app and work through the short setup — or skip it entirely, the
defaults are safe either way.

**Then go to Settings → Reliability before you rely on it for a real night.**

This is the step people skip and then wonder why nothing played. Android and
phone manufacturers stop background apps aggressively, and that screen checks
everything that matters — permissions, battery settings, Do Not Disturb, alarm
volume, audio output — and links straight to whatever needs changing.

On a Samsung Galaxy it is not optional. One UI puts unused apps to sleep after
about three days by default, which will stop cues playing.

Then try:

- **"Play a cue in 2 minutes"** — tap it, lock the phone, put it down. If you
  hear it, the whole alarm and audio path works on your device.
- **"Dry run"** — plays the whole night's cues compressed into a few minutes, so
  you can set the volume in bed rather than discovering at 4am that it is too
  quiet or too loud.

## Verifying your download (optional)

Every release includes `SHA256SUMS.txt`, generated by the GitHub Actions build.
To check your file matches what CI produced:

```bash
sha256sum lucid-dreamer-v0.1.0.apk
```

Compare it against the line in `SHA256SUMS.txt`.

You can also confirm for yourself that the app cannot reach the network:

```bash
aapt dump permissions lucid-dreamer-v0.1.0.apk | grep INTERNET
```

That command returns nothing, because the permission is not declared. The app is
structurally incapable of sending your dream journal anywhere.

## Updating

Download the newer APK and install it over the top. Your data is kept.

One caveat: Android will refuse an update signed with a *different* key. If you
switch between the debug build and a signed build, you have to uninstall
first — **which deletes your dream journal**. Export it first from
Settings → Privacy → Export.

## Uninstalling

Uninstalling deletes everything, including your journal. There is no cloud copy,
by design. Export first if you want to keep it.

## Building it yourself instead

You do not have to trust a downloaded binary. The whole app builds from source
with no API keys and no proprietary dependencies — see
[docs/BUILDING.md](docs/BUILDING.md). Cloning it into Android Studio and pressing
Run is genuinely all it takes.
